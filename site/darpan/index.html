    Make photos for any date

    ● Connected on this device. The Studio can get any date’s photos ready.

    Once on each device, so the Studio may ask GitHub to make a day’s photos:

    1. Open this GitHub page (signed in as you).
    2. Under Repository access choose Only select repositories and pick bapas-diary.
    3. Check Actions says Read and write, then press Generate token and copy it.
    4. Paste it here and press Connect.
